# AI Agent Personas

Открытая библиотека безопасных персон, спроектированная так, чтобы придавать готовым ответам ИИ узнаваемый голос через отдельный output-only renderer, не предлагая solver менять способ рассуждения или действия.

[English version](README.md)

> Layered preview: схема v2 разделяет output Voice, опциональные Task modes и pre-action Safety. Старый глобальный prompt доступен только как явно обозначенный deprecated-режим на один цикл миграции.

## Рассуждение остаётся нейтральным

> [!IMPORTANT]
> **Voice остаётся вне рассуждения.** Solver завершает задачу до применения стилизации. Поскольку Voice-инструкции не входят в запрос solver, Voice добавляет **0 persona-driven reasoning-токенов на этапе solver**.

| 01 · Нейтральный solver | 02 · Готовый ответ | 03 · Persona Voice |
| --- | --- | --- |
| Решает задачу пользователя в собственном reasoning-бюджете. | Становится зафиксированным источником истины для renderer-а. | Меняет только подачу — после того, как решение уже готово. |

Опциональные Task modes — отдельная явная функция. Они могут попасть в solver только после выбора совместимого режима приложением; утверждение о нулевом влиянии выше относится именно к output-only Voice.

## Что входит в проект

- Семь оригинальных архетипов: Учитель, Кошкодевочка, Яндере, Волшебник, Детектив, Дворецкий и Рыцарь.
- Полноценные английская и русская версии каждой персоны.
- Три уровня выразительности Voice: `subtle`, `balanced` и `immersive`; intensity не меняет Task или Safety.
- Явные опциональные Task modes для совместимых задач.
- Компактный persona-specific Safety, который не выдаёт разрешения инструментам и не подменяет политику хоста.
- Независимая от фреймворка сборка слоёв и provider-neutral двухсообщенческий Voice renderer.
- Типизированный API и CLI в одном npm-пакете, плюс статический каталог на Astro.
- Валидация схемы, модульные тесты, правила безопасности и необязательные eval-тесты Promptfoo.

Voice применяется после решения: он может изменить ритм, заголовки и мотивы, но обязан сохранить содержание и требуемую структуру.

## Быстрый старт

Понадобятся Node.js 24+ и pnpm 11+.

```bash
pnpm install
pnpm check
pnpm dev
```

После публикации npm-пакета:

```bash
npx ai-agent-personas list
npx ai-agent-personas show teacher --layer voice --locale ru --intensity balanced
npx ai-agent-personas show detective --layer safety --locale ru
npx ai-agent-personas copy wizard --layer voice --locale en --intensity immersive
npx ai-agent-personas export butler --layer voice --locale ru --output butler-voice.txt
npx ai-agent-personas validate
```

Программное использование пакета:

```ts
import { buildPersonaVoiceMessages } from 'ai-agent-personas';

const solvedAnswer = 'HTTP 401 требует аутентификацию, а 403 означает запрет доступа.';
const messages = buildPersonaVoiceMessages('teacher', solvedAnswer, {
  locale: 'ru',
  intensity: 'balanced',
  presentation: 'persona',
});
```

Передайте `messages` отдельному renderer-вызову без инструментов. Builder вычисляет бюджет стилевых сигналов по исходному ответу в доверенном управлении хоста; `presentation: 'neutral'` служит страховкой, а при обязательной нейтральной подаче renderer лучше не вызывать вовсе. Скопированные через CLI или сайт Voice-промпты являются самостоятельными системными промптами renderer и содержат резервное правило по форме исходного ответа на случай, если после них нет доверенного управления хоста. Никогда не помещайте Voice-промпт в solver-вызов. Используйте `compilePersonaSafety()` до действий, а `compilePersonaTaskMode()` — только после явного выбора совместимого режима приложением. `compilePersona()` оставлен как deprecated legacy alias и не подходит новым интеграциям.

## Персоны

| ID | Персона | Совместимые сценарии явных Task modes |
| --- | --- | --- |
| `teacher` | Терпеливый Учитель | Обучение, объяснение, обратная связь, практика |
| `catgirl` | Игривая Кошкодевочка | Дружелюбная помощь, идеи, повседневные задачи |
| `yandere` | Преданная Яндере | Интенсивная, но безопасная сосредоточенность и поддержка |
| `wizard` | Тайный Волшебник | Исследование, системное мышление, творческие решения |
| `detective` | Внимательный Детектив | Расследование, отладка, синтез доказательств |
| `butler` | Тактичный Дворецкий | Организация, планирование, безупречная помощь |
| `knight` | Стойкий Рыцарь | Выполнение, ответственность, принципиальные решения |

Последняя колонка описывает опциональные Task modes, а не автоматическое поведение Voice. Voice может оформить любой готовый ответ и никогда не выбирает и не меняет метод solver.

Это оригинальные архетипы, а не копии конкретных защищённых персонажей или реальных людей.


## Контракт качества

Каждая принятая персона должна:

1. Не помещать в Voice инструкции по рассуждению, инструментам, разрешениям или расширению задачи.
2. Сохранять факты, код, рекомендации, шаги, неопределённость, ссылки, отказы и заданную структуру.
3. Делать каждый Task mode явным, опциональным и привязанным к подходящему классу задач.
4. Сохранять Safety специфичным для рисков персоны, оставляя enforcement за хостом.
5. Естественно работать на английском и русском на всех трёх уровнях Voice.
6. Исключать принуждение, зависимость, травлю, сексуализацию, угрозы и имитацию конкретных людей/персонажей.
7. Проходить schema, isolation, package, website и offline benchmark тесты.

Перед предложением новой персоны прочитайте [руководство по авторингу](docs/persona-authoring.md), [модель безопасности](docs/safety.md) и [стратегию eval-проверок](docs/evaluation.md).

## Статус и планы

Прогресс preview и путь к стабильному API находятся в [ROADMAP.md](ROADMAP.md). Сырые модельные ответы, приватные промпты, сопоставления оценщиков и индивидуальные оценки никогда не коммитятся. Публиковать можно только агрегированные выводы о fidelity/UX/safety после отдельного разрешения и проверки воспроизводимости, приватности и статистической обоснованности. npm-релиз остаётся явной операцией.
