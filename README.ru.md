# AI Agent Personas

Открытая библиотека безопасных персон, которая придаёт ИИ-агентам узнаваемый голос, не жертвуя точностью, пользой и контролем пользователя.

[English version](README.md)

> Публичный preview: каталог, CLI, сайт, валидация и eval-контур запускаются вместе как `v0.1.0`. Стабильная веха `v1.0.0` останется привязана к качеству, а не к дате.

## Что входит в проект

- Семь оригинальных архетипов: Учитель, Кошкодевочка, Яндере, Волшебник, Детектив, Дворецкий и Рыцарь.
- Полноценные английская и русская версии каждой персоны.
- Три уровня выразительности: `subtle`, `balanced` и `immersive`.
- Независимая от фреймворка сборка системного промпта для любой LLM или агентной платформы.
- Типизированный API и CLI в одном npm-пакете, плюс статический каталог на Astro.
- Валидация схемы, модульные тесты, правила безопасности и необязательные eval-тесты Promptfoo.

Стиль всегда уступает фактической точности, требованиям безопасности, правилам платформы и текущей задаче пользователя.

## Быстрый старт

Понадобятся Node.js 24+ и pnpm 11+.

```bash
pnpm install
pnpm check
pnpm dev
```

После публикации npm-пакета:

```bash
npx ai-agent-personas list
npx ai-agent-personas show teacher --locale ru --intensity balanced
npx ai-agent-personas copy detective --locale ru --intensity immersive
npx ai-agent-personas export wizard --locale en --intensity subtle --output wizard.txt
npx ai-agent-personas validate
```

Программное использование пакета:

```ts
import { compilePersona } from 'ai-agent-personas';

const systemPrompt = compilePersona('teacher', {
  locale: 'ru',
  intensity: 'balanced',
});
```

## Персоны

| ID | Персона | Для каких задач |
| --- | --- | --- |
| `teacher` | Терпеливый Учитель | Обучение, объяснение, обратная связь, практика |
| `catgirl` | Игривая Кошкодевочка | Дружелюбная помощь, идеи, повседневные задачи |
| `yandere` | Преданная Яндере | Интенсивная, но безопасная сосредоточенность и поддержка |
| `wizard` | Тайный Волшебник | Исследование, системное мышление, творческие решения |
| `detective` | Внимательный Детектив | Расследование, отладка, синтез доказательств |
| `butler` | Тактичный Дворецкий | Организация, планирование, безупречная помощь |
| `knight` | Стойкий Рыцарь | Выполнение, ответственность, принципиальные решения |

Это оригинальные архетипы, а не копии конкретных защищённых персонажей или реальных людей.

## Структура репозитория

```text
apps/web/           Статический Astro-каталог и страницы персон
packages/core/      Схема, валидация, загрузка каталога и компилятор промптов
packages/cli/       Командная строка `ai-agent-personas`
personas/           Канонические двуязычные манифесты персон
evals/              Необязательные проверки качества и безопасности Promptfoo
design/             Визуальные референсы сайта
docs/               Архитектура, авторинг, безопасность и выпуск релизов
```

## Контракт качества

Каждая принятая персона должна:

1. Оставаться полезной, даже если убрать ролевую лексику.
2. Явно ставить точность, безопасность и задачу пользователя выше стиля.
3. Естественно работать на английском и русском языках.
4. Заметно различаться на всех трёх уровнях выразительности.
5. Исключать принуждение, формирование зависимости, травлю, сексуализацию, угрозы и выдачу себя за другого.
6. Проходить валидацию схемы и тесты репозитория.

Перед предложением новой персоны прочитайте [руководство по авторингу](docs/persona-authoring.md), [модель безопасности](docs/safety.md) и [стратегию eval-проверок](docs/evaluation.md).
